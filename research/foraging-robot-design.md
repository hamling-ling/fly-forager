## 0. デモしたいこと（一文）

**同じロボット・同じ食べ物で、内部状態だけを変えると「食べる／食べない」の判断が変わる。**
横の画面にはそのときどのニューロンが効いているか（Δマップ）を出し、
判断の変化が回路の内訳の変化と対応することを見せる。

## 1. 載せるもの — 測り済みのパラメータだけを使う

実験D（用量反応曲線）と実験E（出力マッチ Δマップ）の実測値がそのまま仕様になる。

### 1.1 状態の定義（端点のみ。補間はしない — §5参照）

| 状態 | k_P（末梢ゲイン） | g_GABA（ブレーキゲイン） | EC50（公称 Hz） | 10 Hz 閾値（公称 Hz） | MN9 @公称150 Hz |
|---|---|---|---|---|---|
| 状態なし base | 1.0 | 1.0 | 72.4 | 60 | 77.7 |
| 飢餓 H3 | 1.5 | 0.7 | 42.3（Δ −30.2） | 40 | 124.3 |
| 満腹 S3 | 0.67 | 1.3 | 113.3（Δ +40.9） | 100 | 29.6 |

出典: `expD-hunger-satiety-design.md` 実行記録。EC50・閾値とも事前登録した読み出し。
留保: 公称軸のシフトは一部定義的（H1/S1 の純粋再スケール予測は 48.3 / 108.1 に対し
実測 52.2 / 93.4）。定義的でない実質はブレーキ側（H2/S2）で、入力を変えずに曲線が動いたこと。

### 1.2 食べる／食べないの判定 — MN9 の 10 Hz 閾値

実験Dで事前登録した閾値（MN9 が 10 Hz を初めて超える入力レート）をそのまま
口吻伸展（PER）のオン／オフに使う。10 Hz は苦味条件の床 0.3 Hz とノイズ ±1–2 Hz
をはっきり上回る値として選ばれたもの。

- 公称 60 Hz の食べ物トークン（中濃度）: base では MN9 28.3 Hz → 食べる。
  H3 では同じトークンがさらに強く食べる側へ、S3 では MN9 が床近くまで落ちて食べない。
- デモ用の3段階トークン（公称レート換算・名目）: 薄い = 30 Hz、普通 = 60 Hz、濃い = 150 Hz。
  - 薄い（30 Hz）: H3 で MN9 ≈ 29.6 Hz（実験E較正値）→ 食べる。S3 ではほぼ 0 → 食べない。
  - 普通（60 Hz）: base 28.3 Hz → 食べる。S3 では 0.5 Hz（実験E設計時の予測）→ 食べない。
  - 濃い（150 Hz）: S3 でも MN9 29.6 Hz → 食べる。満腹でも濃いものだけ受け付ける、が再現できる。

### 1.3 画面に出す Δマップ — 出力マッチ済みの18個

実験Eの要点18個（MN9 ≈ 30 Hz に出力マッチ済み）がデモの表示内容になる。
状態で入れ替わる組がそのまま見せ場:

- 飢餓で増幅: CB0192 +8.6 → **+13.5**、DNge059 +5.1 → **+12.8**、CB0616 +9.6 → **+14.4**。
- 飢餓でブレーキ弱化: DNge031 −29.2 → −20.4（GABA スケーリング ×0.7 の予測と一致）。
- 満腹でブレーキ優位: DNge031 **−48.4**（予測 −38 より強い。外すと MN9 30.5 → 約79 Hz へ解放）。
- 満腹で選択的オフ: CB0192 +0.9、CB0883 +1.2、DNge059 +0.2、AN_GNG_30 +2.2。
  一方で残る組: CB0277 +17.1、CB0499 +10.4、CB0493 +10.7、CB0553（623211725）+10.2。

出典: `expE-state-maps.md`。全64への拡張は要点セットが豊かだったため未実施。

## 2. 機体とセンサーの構成案

### 2.1 車体

fly-car の車体流用か、新規の小型車体かは未決定。fly-car は Arduino UNO Q +
カメラ + 連続回転サーボ（FS90R）駆動で、ループ約 221 ms（非同期化マージ済みで
約 100 ms 見込み、実機未走行）という前提がある。採餌ロボットは「近づく」より
「前に置かれたトークンを味わう」が主動作なので、走行性能は fly-car ほど要らない。
判断材料: fly-car を流用すると実機リハーサルと競合する。新規小型車体の方が
展示の切り分けは楽。

### 2.2 口吻（プロボシス）アーム

MN9 の発火 → サーボアームの伸展、という対応を取る。注意点が1つある。
fly-car の駆動サーボ FS90R は連続回転型で、位置決めには向かない。
口吻には**位置決め用の通常サーボが別途要る**（機種未選定）。MN9 の発火率から
伸展角への換算は設計上の決め事で、測り済みの数値ではない。案: 10 Hz を伸展開始、
30 Hz で全伸展、としておき、デモで見て調整する。

### 2.3 味覚センサー（糖濃度の読み取り）

トークンの「糖の濃さ」を公称レート（30 / 60 / 150 Hz 相当）に変換する入力が要る。
候補は色（トークンの色濃度をカメラで読む — fly-car のカメラ流用可）か
導電率（糖水の濃度を電気的に読む）。どちらも未選定・未検証。
色なら fly-car の色閾値の流用が利くが、照明依存。導電率は照明に強いが
トークン側の作り込みが要る。選定は次の判断点の1つ。

### 2.4 状態変数（空腹⇄満腹）の動かし方

- **第一案（推奨）: 二値スイッチ。** H3 か S3 かだけを切り替える。測ったのは
  端点だけなので、これだけが「測ったものを載せる」形になる。デモでは
  「食べた回数」や「経過時間」で切り替える。
- 第二案: 連続状態。k_P と g_GABA を端点の間で補間する。滑らかな性格変化に
  なるが、中間の値は未測定で、補間が正しい保証はない。やるなら先に in silico で
  中間点（例: k_P 1.2、g_GABA 0.85）を測る必要がある。

## 3. 載せる回路の範囲 — 全脳は載せない

全脳モデル（Shiu モデル、Brian2、VM で 5試行チャンク約40–45秒）は実時間では
回らない。実機に載せるのは、糖アッセイで実際に発火する部分回路の抽出になる。
含める最小セットの候補（実験Eの要点18個を核とする）:

- 入力: 糖 GRN（糖入力の入口）。
- ドライバー: CB0192、CB0277、CB0883、CB0499、CB0493、CB0553（2個）、
  CB0616、DNge059、AN_GNG_30、CB0393、CB0700。
- ブレーキ: DNge031、CB0480 ペア、CB0248 ペア。
- 判定役: CB0889（CB0883 の veto 候補。ただし二重サイレンシングは設計済み・未承認で、
  veto の証明はまだない。載せるかどうかはその結果次第）。
- 出力: MN9。

抽出の作業量は未見積もり。ニューロン数・シナプス数の数え上げと、抽出後の
in silico 再検証（H3/S3 の EC50 シフトが残るか）が次の作業になる。

### 3.1 数え上げの結果（2026-11-20 実施）

- 最小核（糖 GRN 20 + 要点18 + MN9 = 39 ニューロン）：内部 513 辺・
  6,236 シナプス。ただし要点18の効果の大半は集合外の中間ニューロン経由
  なので、この最小核では実験Eの地図は再現できない見込み。
- ベースラインで発火する集合（30試行の和集合）：433 ニューロン、
  内部 20,306 辺・242,398 シナプス。
- **全条件（C1／C2／苦味／スクリーン全サイレンシング、保存済み330ファイル）
  の和集合：687 ニューロン、内部 37,601 辺・418,845 シナプス。**
  全脳 54,492,922 シナプスの 0.77%。抽出候補はこれ。
  根拠：この LIF モデルには自発発火がないので、ベースラインで発火しない
  ニューロンは因果的に寄与しない。和集合を全条件に広げるのは、状態や
  サイレンシングで新たに発火するニューロンを取りこぼさないため。
- 実時間性の見通し（概算）：全脳は 1 秒の試行に最速で約9秒。シナプス数で
  単純比例させると抽出回路は約70 ms／秒で、オーバーヘッドを10倍見ても
  実時間圏内。ただしこれは比例換算の見積もりで、実測は §7-2 の再検証で取る。

## 4. デモの台本（案）

1. 薄いトークンを置く。状態 = 飢餓（H3）→ 口吻が伸びて食べる。画面は CB0192・DNge059 が
   効いている地図。
2. 同じトークン、状態 = 満腹（S3）に切り替え → 口吻が伸びない。画面は DNge031 が
   −48.4 で支配的な地図に切り替わる。
3. 濃いトークンに替え、満腹のまま → 口吻が伸びる。「満腹でも濃いものだけは食べる」。
4. （任意・未測定）苦味混じりトークン: 飢餓では我慢して食べ、満腹では即拒否。
   これは実験D §3.4 の苦味耐性系列で、in silico では未実施。デモに入れるなら
   先にシミュレーションで測る。

## 5. 正直な留保（発表・展示で断ること）

- LIF モデル・一様重み・伝達物質は予測、という実験D/Eと同じ留保がそのまま付く。
- ドーパミンの GPCR 動態はモデルに入っていない。入っているのは「修飾の結果としての
  ゲイン変化」だけ。
- 濃度と入力レートの対応は名目。mM への換算はできない。主張できるのはシフトの
  方向と相対量まで。
- 状態の二値スイッチは展示用の操作で、実際のハエの空腹が二値だという主張ではない。
- CB0883 の veto は未証明。画面で CB0889 を veto 役として断定しないこと。
