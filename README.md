# Fly-Forager

ハエの脳の摂食回路で、食べる／食べないを決める差動二輪ロボット。

ショウジョウバエ雌の全脳コネクトーム（FlyWire v783、138,639 ニューロン）のモデルで、糖入力から口吻を動かす MN9 までの摂食回路を実測した。空腹と満腹を、末梢の糖感度と GABA ブレーキの強さとして回路に入れると、用量反応曲線が左右に動き、各ニューロンの寄与の地図そのものが状態で変わる。この実測した回路を 687 ニューロンに抽出して、ロボットに載せる計画である。プロジェクトの狙いは [ポンチ絵](poster/foraging-robot-poster.pdf) にある。

## 実測済みのこと

- 用量反応の EC50 は基準 72.4 Hz。空腹（末梢ゲイン 1.5、GABA ゲイン 0.7）で 42.3 Hz、満腹（0.67、1.3）で 113.3 Hz へ動く。MN9 が 10 Hz を超える名目入力は 60 → 空腹 40／満腹 100 Hz
- 出力を揃えても（MN9 ≈ 30 Hz）寄与マップは状態で変わる。満腹ではブレーキ DNge031 の寄与が Δ −48.4 まで強まり、ドライバの一部（CB0192、CB0883、DNge059）が選択的に消える。空腹ではドライバが増幅する
- 抽出した部分回路（687 ニューロン、37,601 結合、418,845 シナプス、全脳の 0.77%）は全脳の EC50 を再現する（72.1／41.7／105.0）。1 秒の試行を約 1 秒で計算できる

食べる／食べないの境は、用量反応の読み取りに使った MN9 の 10 Hz をそのまま使う。

## 構成

- `src/flyforager/` — パッケージ。`subcircuit/` に抽出回路の接続表が入る
- `research/` — 設計書と決定シート
- `poster/` — ポンチ絵
- `scripts/` — 全脳データの入手手順
- `data/` — 全脳データの置き場（中身はリポジトリに入れない）

## 必要な環境

- シミュレーション: Linux と Python 3.12。パッケージは `brian2`、`numpy`、`pandas`、`scipy`、`pytest`

## データについて

全脳の接続表とモデルは、FlyWire のデータ（CC BY-NC 4.0）と Shiu et al. のモデルコード（MIT）を使う。入手手順は [scripts/README.md](scripts/README.md) に書いた。このリポジトリに入っているのは、自分で抽出した 687 ニューロンの部分回路だけである。

## 正直なところ

- モデルは漏れ積分発火で、シナプス重みは一様、伝達物質の符号は予測である
- 名目入力レートと実際の糖濃度の対応は仮のもので、向きと相対量だけに意味がある。ドーパミンなどの分子の動きそのものは入っていない
- 機体の決め事（状態の切り替え方、車体、センサ、口吻、計算機）は [決定シート](research/foraging-robot-decisions.md) で相談中である
